# DeepSeek в кармане

Самодельный карманный гаджет на ESP32-C3: чат с DeepSeek, инженерный калькулятор, справочник, конспекты, игры и общая «Комната» для владельцев таких же устройств.

## Что нужно

- ESP32-C3 Super Mini
- дисплей ST7789 240×240 (без вывода CS)
- аналоговый джойстик KY-023
- по желанию: LiPo-аккумулятор, плата зарядки TP4056, переключатель

## Подключение

| Дисплей | ESP32-C3 |   | Джойстик | ESP32-C3 |
|---------|----------|---|----------|----------|
| SCL     | GPIO4    |   | VRx      | GPIO0    |
| SDA     | GPIO6    |   | VRy      | GPIO1    |
| DC      | GPIO5    |   | SW       | GPIO7    |
| RES     | GPIO21 (или GPIO3, см. ниже) | | +5V | 3V3 |
| BLK     | GPIO10   |   | GND      | GND      |
| VCC     | 3V3      |   |          |          |
| GND     | GND      |   |          |          |

Вместо проводов можно заказать **печатную плату-основу**: см. папку [`hardware`](hardware/README.md).

### Батарея и пищалка (по желанию)

- **RES экрана** можно подключить к GPIO21 (TX) или к GPIO3: прошивка подаёт сброс на оба вывода и сама понимает схему.
- **Проценты заряда:** RES на GPIO21, два резистора по 100 кОм: один от «+» питания (вывод 5V платы) к GPIO3, второй от GPIO3 к GND. Делитель определяется сам при включении.
- **Пищалка:** «+» на GPIO20 (RX), «−» на GND. Для активной пищалки в скетче `BUZZER_ACTIVE = true`. Звук настраивается в меню: нет / сигналы / всё.

## Сборка

1. На GitHub: **Code → Download ZIP**. Распакуйте архив (правой кнопкой → «Извлечь всё»), не открывайте файлы прямо из ZIP.
2. Скетч лежит в папке **`deepseek_c3`**: откройте `deepseek_c3/deepseek_c3.ino`. В Arduino IDE должны появиться вкладки с остальными файлами (`admin.h`, `calc.h`...).
3. Пакет плат **esp32** (Espressif) 3.x. Библиотеки (Скетч → Подключить библиотеку → Управлять библиотеками): **Adafruit ST7735 and ST7789**, **Adafruit GFX**, **ArduinoJson** (7.x), **TJpg_Decoder** (Bodmer).
4. Инструменты:
   - Плата: **ESP32C3 Dev Module**, разметка **Partition Scheme: Minimal SPIFFS (1.9MB APP with OTA/190KB SPIFFS)**. Или плата **Nologo ESP32C3 Super Mini** с разметкой **Huge APP**: прошивка выйдет на 16 КБ меньше (GitHub собирает именно так). Настоящую разметку в обоих случаях задаёт файл `partitions.csv` в папке скетча.
   - **USB CDC On Boot: Enabled** - обязательно: иначе вывод в монитор порта идёт через GPIO21 и сбрасывает экран
   - **Erase All Flash Before Sketch Upload: Disabled** - иначе каждая прошивка стирает сеть, ключ и файлы
5. Загрузить. Проводом это нужно один раз: дальше обновления приходят по воздуху.

## Первый запуск

Гаджет создаёт сеть Wi-Fi **DeepSeek-Setup**. Подключитесь к ней с телефона: откроется страница, где вводятся сеть Wi-Fi и ключ DeepSeek (получить: platform.deepseek.com). Ключи и пароли хранятся только в памяти платы, в файлах прошивки их нет.

## Возможности

- чат с DeepSeek с памятью переписки, ответ печатается по мере генерации; «решить по шагам», «объяснить проще»
- русский, английский и китайский языки; экранная клавиатура с подсказками слов
- шаблоны вопросов, сохранённые ответы и конспекты (читаются без интернета)
- справочник: формулы, константы, таблица Менделеева
- инструменты: инженерный калькулятор (с переменной x, графиками функций и решением уравнений - см. ниже), Википедия, картинки (Wikimedia Commons), погода, курсы ЦБ, часы, таймер, секундомер
- игры, в том числе шахматы против DeepSeek или самой платы
- «Райдер», общая таблица рекордов игроков и крестики-нолики по сети (через комнату)
- «Подземелье 3D» - стрелялка от первого лица (ручка - идти и поворачивать, кнопка - выстрел)
- «Пульт» (Инструменты): ИК-пульты из базы Flipper-IRDB - скачиваются с GitHub прямо с гаджета или загружаются файлом .ir с телефона.
  Нужен ИК-светодиод: GPIO8 -> база NPN-транзистора (S9014), коллектор -> 5V, эмиттер -> «+» светодиода, «-» светодиода -> резистор 33-68 Ом -> GND
- фонарик: Настройки → Фонарик. Белый светодиод на GPIO2 через транзистор (схема - в начале скетча, рядом с PIN_LED)
- чувствительность джойстика: Настройки → Джойстик (1 - отклонять до упора, 5 - хватает лёгкого наклона)
- галерея: картинки с телефона или из поиска хранятся в памяти платы
- до 5 сетей Wi-Fi, автогашение экрана, заставка с часами
- **Комната** — общий чат всех таких гаджетов

## Главный экран

После включения открывается главный экран, как у телефона. Сверху строка состояния: время, Wi-Fi, заряд, новые сообщения комнаты. Ниже иконки приложений 3×3 на нескольких страницах. Ручкой выбирается иконка; если упереться в край, открывается соседняя страница. Нажатие открывает приложение, удержание кнопки возвращает назад.

Чат с DeepSeek теперь отдельное приложение «DeepSeek». Удержание кнопки на его клавиатуре открывает меню чата: «На главный экран», «Новый чат», шаблоны вопросов, сохранённое.

Если вверх и вниз на ручке перепутаны: **Настройки → Ось Y джойстика**.

**Настройки → Поворот экрана** поворачивает картинку на 90° за нажатие (экран квадратный, всё помещается), например чтобы держать гаджет боком. Ручка поворачивается вместе с картинкой.

## Игры вдвоём рядом (без интернета)

**Игры → Крестики рядом** — два гаджета связываются напрямую по радио (ESP-NOW), без роутера и интернета, на расстоянии примерно до 100 м. На время игры Wi-Fi отключается от сети, а после игры подключается снова.

## SD-карта

Модуль microSD подключается вместо ИК-пульта, фонарика и пищалки:

| SD-модуль | ESP32-C3 |
|---|---|
| SCK | GPIO8 |
| MOSI | GPIO2 |
| MISO | GPIO20 |
| CS | GPIO9 |
| VCC | 5V (выход модуля зарядки; на модуле свой стабилизатор 3,3 В) |
| GND | GND |

Ещё два резистора по 10 кОм: от GPIO2 к 3V3 и от GPIO9 к 3V3. Эти выводы при включении должны быть в высоком уровне, иначе плата не загрузится. Карта нужна до 32 ГБ, в формате FAT32.

Включение: **Настройки → SD-карта** (гаджет перезапустится). После этого:

- галерея хранится на карте (до 99 картинок вместо ~10);
- **Настройки → Обновление → Сборки на SD-карте**: скачать обе сборки на карту и переключаться между ними без интернета.

Шина SPI у платы одна, а у экрана нет вывода CS, поэтому на время работы с картой выводы шины переключаются на неё, а потом обратно на экран.

## Bluetooth и две сборки

Bluetooth весит около 250 КБ, и всё вместе в память на 4 МБ не помещается. Поэтому GitHub собирает две прошивки:

- **полная сборка** (`firmware.bin`): всё, кроме Bluetooth;
- **сборка с Bluetooth** (`firmware-ble.bin`): связь с телефоном и пульт для музыки на телефоне, но **без** картинок из интернета (галерея с телефона остаётся), шахмат, «Подземелья 3D», «Гонок», «Райдера», «Викторины», «Истории», ИК-пульта и фонарика.

Переключение: **Настройки → Обновление → Сменить сборку**. Настройки, сети и файлы сохраняются. Для сборки в Arduino IDE поставьте в начале скетча `#define ENABLE_BLE 1` и установите библиотеку **NimBLE-Arduino 1.4.3**.

В сборке с Bluetooth включите **Настройки → Bluetooth**. Гаджет называется **DS-<метка>**.

- **Телефон как клавиатура и уведомления:** откройте в Chrome на Android страницу [yacovgopnik.github.io/deepseek-pocket/ble.html](https://yacovgopnik.github.io/deepseek-pocket/ble.html) и нажмите «Подключить». Подойдёт и приложение Serial Bluetooth Terminal (режим Bluetooth LE). Текст попадает в открытое поле ввода, например как вопрос DeepSeek. Если поле ввода не открыто, он всплывает как уведомление. Строка с `N:` в начале — всегда уведомление, с `T:` — только вставить.
- **Пульт для телефона:** на телефоне в настройках Bluetooth подключитесь к **DS-<метка>** (сопряжение). На гаджете: приложение Bluetooth → Пульт. Ручка влево и вправо — трек, вверх и вниз — громкость, нажатие — пауза.

Когда Bluetooth включён, Wi-Fi и Bluetooth делят память. Если запросы в интернет начнут срываться, выключите Bluetooth.

## Администратор

Один человек может быть администратором всех гаджетов с этой прошивкой. Команды подписываются ключом, который получается из логина и пароля админа (ECDSA P-256). В прошивке хранится только открытый ключ `ADMIN_PUBKEY`, по которому гаджеты проверяют подпись. Подделать команду без пароля нельзя, даже зная исходный код. Пароль нигде не записывается.

Как стать админом:

1. **Настройки → Администратор → Создать ключ**: ввести логин и пароль. Открытый ключ появится на экране и в мониторе порта (115200).
2. Вписать его в `ADMIN_PUBKEY` в начале скетча и выпустить новую версию.
3. **Настройки → Администратор → Войти** с теми же логином и паролем. Вход действует до перезапуска; на главном экране появляется приложение «Админ».

Что может админ:

- **Гаджеты на связи**: имя, комната, версия прошивки, заряд. Для каждого гаджета: обновить прошивку, перезапустить, выгнать из комнаты, заблокировать.
- **Объявление всем**: всплывает на экране всех гаджетов, в том числе тех, кто подключится позже.
- **Сообщения комнаты**: удалить сообщение у всех, заблокировать автора. Заблокированный не может писать, а его сообщения у других не показываются.
- **Закрепить в комнате**: строка сверху экрана комнаты.
- **Обновить все гаджеты / перезапустить все**.

Владелец гаджета видит каждое действие админа. Обновление и перезапуск начинаются через 10 секунд, и их можно отменить кнопкой. Команды идут через тот же открытый сервер, что и «Комната», поэтому их получают только гаджеты, у которых в комнате задано имя и включены «Сообщения в фоне». Старые и повторённые команды не принимаются: нужно точное время, гаджет берёт его из интернета.

## Калькулятор: функции, графики, уравнения

Клавиша **2nd** переключает на вторую страницу клавиш, **1st** возвращает обратно. Переменная **x** есть на обеих страницах.

- **Функции.** Вводите выражение с x: `2x²-3x+1`, `sin(x)/x`, `√x`, `3x^4`. Неявное умножение работает (`2x`, `3(x+1)`). Результата у такого выражения нет, калькулятор пишет «функция f(x)».
- **График y(x)** (2nd → `y(x)`): вверх/вниз - масштаб, влево/вправо - сдвиг, нажатие - курсор со значениями x и y, удержание - назад. Масштаб по y подбирается сам. Если выражение пустое, строится последняя функция. Для sin/cos/tan в градусах окно по умолчанию шире (720°).
- **Уравнения** (2nd → `x=?`). Знак равенства вводится клавишей `L=R`: `x²=x+2`, `3x^4=48`; без знака равенства считается «выражение = 0».
  - Многочлены и одночлены до 8-й степени решаются точно: рациональные корни находятся целиком, показывается кратность корней, комплексные корни выводятся как `a ± bi`.
  - Остальные уравнения (`sin(x)=0,5`, `1/x=2`, `√x=2`) решаются приближённо: ищется смена знака на отрезке [-100; 100] (для тригонометрии в градусах [-720; 720], в радианах [-20; 20]). Корни, в которых график лишь касается оси, так не находятся.

## Комната

Гаджеты с этой прошивкой встречаются в общей комнате `lobby` на открытом MQTT-сервере (`broker.emqx.io`, тема `dspocket/v1/<комната>`, сообщение: `метка<TAB>имя<TAB>текст`). Присутствие («кто в комнате») идёт в теме `<комната>/p`, аватарки 24×24 — в `<комната>/a/<метка>` (576 байт, сохраняемое сообщение). Сообщение, начатое с `@ai`, получает ответ DeepSeek, который видят все. В комнату можно зайти и из браузера: страница `room.html`. Сообщения **не шифруются** и не хранятся: их видят все, кто сейчас в комнате. Не пишите туда пароли и личные данные. Сервер и комнату по умолчанию можно поменять в начале скетча (`MQTT_HOST`, `ROOM_DEFAULT`).

## Шрифты

Латиница, кириллица и знаки формул сделаны из DejaVu Sans Mono, иероглифы — из GNU Unifont и Noto Sans CJK. У этих шрифтов свои свободные лицензии.

## Обновление по воздуху

На гаджете: **Настройки → Обновление → Проверить в интернете** (или «С телефона» - загрузить файл `.bin` через страницу гаджета). Если обновление оборвалось, остаётся старая прошивка.

Новые версии собираются сами: при каждом изменении кода GitHub Actions собирает скетч и кладёт `firmware/firmware.bin` и номер версии в `firmware/version.txt`. Гаджет сравнивает этот номер со своим и предлагает обновиться. Репозиторий задаётся строкой `OTA_REPO` в начале скетча.

Китайский язык выключен (`ENABLE_CJK 0` в начале скетча), иначе прошивка не помещается в разметку с обновлением по воздуху.
