# DeepSeek в кармане

Самодельный карманный гаджет на ESP32-C3. Умеет:
- чат с DeepSeek;
- инженерный калькулятор с графиками и решением уравнений;
- справочник, конспекты, игры;
- общую «Комнату» для владельцев таких же устройств;
- игры вдвоём по радио;
- галерею на SD-карте;
- вывод картинок и экрана с компьютера;
- управление с телефона.

Обновляется по воздуху с этого репозитория.

## Что нужно

- ESP32-C3 Super Mini
- дисплей ST7789 240×240 1,3" (без вывода CS)
- аналоговый джойстик KY-023
- по желанию:
  - LiPo-аккумулятор и модуль зарядки с повышением до 5 В (USB-C), выключатель;
  - модуль microSD (например, V717) с конденсатором 100 мкФ;
  - пищалка, ИК-светодиод, белый светодиод (без SD-карты).

## Подключение

| Дисплей | ESP32-C3 |   | Джойстик | ESP32-C3 |
|---------|----------|---|----------|----------|
| SCL     | GPIO4    |   | VRx      | GPIO0    |
| SDA     | GPIO6    |   | VRy      | GPIO1    |
| DC      | GPIO5    |   | SW       | GPIO7    |
| RES     | GPIO21 (или GPIO3, см. ниже) | | +5V | **3V3** |
| BLK     | GPIO10   |   | GND      | GND      |
| VCC     | 3V3      |   |          |          |
| GND     | GND      |   |          |          |

### ESP32-S3 (S3-Zero)

Прошивка сама подставляет распиновку под плату: в Arduino IDE выберите **ESP32S3 Dev Module**, USB CDC On Boot: Enabled, Flash Size: 4MB, PSRAM: QSPI PSRAM, Partition Scheme: Minimal SPIFFS. По воздуху гаджет на S3 сам берёт сборки для S3 (`firmware-s3*.bin`).

| Что | S3-Zero |
|---|---|
| Экран SCL, SDA, DC, RES, BLK | 12, 11, 10, 9, 8 (VCC — 3V3) |
| Джойстик VRx, VRy, SW | 1, 2, 7 (питание — 3V3) |
| SD-карта SCK, MOSI, MISO, CS | 5, 6, 13, 4 (VCC — 5V; у карты своя шина SPI, подтяжки не нужны) |
| Батарея (делитель 100к + 100к) | 3 |
| Пищалка / ИК-светодиод | RX (44) / TX (43) |
| Усилитель MAX98357A: BCLK, LRC, DIN | 14, 15, 16 (VIN — 5V, SD и GAIN не подключать) |
| Микрофон INMP441: SCK, WS, SD | 14, 15, 17 (VDD — 3V3, L/R — GND) |
| Датчик наклона ADXL345: SDA, SCL | 38, 39 (VCC — 3V3, CS — 3V3, SDO — GND); Настройки → Наклон: уровень, калибровка, управление в играх |
| Фонарик / вибромотор | 18 / 40 |
| Не трогать | 0 (кнопка BOOT), 19–20 (USB), 21 (светодиод на плате), 45 (влияет на запуск) |

Выводы 14–18 и 38–40 у S3-Zero — площадки на плате. В нашем гаджете они выведены проводами на отдельную гребёнку. Порядок, если смотреть с гребёнкой вверх: **40, 39, 38, 18, 17, 14, 15, 16**.

### Батарея

- **RES экрана** можно подключить к GPIO21 (TX) или к GPIO3: прошивка подаёт сброс на оба вывода и сама понимает схему.
- **Проценты заряда.** RES подключите на GPIO21. Нужны два резистора по 100 кОм: один от «+» питания к GPIO3, второй от GPIO3 к GND. Прошивка сама находит делитель при включении.

### Выводы, которые делят SD-карта и дополнительные детали

GPIO2, GPIO8, GPIO9 и GPIO20 нужны либо SD-карте, либо пищалке, ИК-пульту и фонарику:

| Вывод | С SD-картой | Без SD-карты |
|---|---|---|
| GPIO8 | SCK карты | ИК-светодиод (через транзистор) |
| GPIO2 | MOSI карты | фонарик (через транзистор) |
| GPIO20 | MISO карты | пищалка |
| GPIO9 | CS карты | — |

Когда включена SD-карта, прошивка не трогает пищалку, ИК и фонарик. При попытке их включить она говорит, что вывод занят картой.

## Сборка в Arduino IDE

Проводом прошивать нужно один раз, дальше обновления приходят по воздуху.

1. На GitHub: **Code → Download ZIP**. Распакуйте архив («Извлечь всё»), не открывайте файлы прямо из ZIP.
2. Скетч лежит в папке **`deepseek_c3`**: откройте `deepseek_c3/deepseek_c3.ino`. В Arduino IDE должны появиться вкладки с остальными файлами (`admin.h`, `calc.h`...).
3. Пакет плат **esp32** (Espressif) 3.x. Библиотеки (Скетч → Подключить библиотеку → Управлять библиотеками):
   - **Adafruit ST7735 and ST7789**, **Adafruit GFX**, **ArduinoJson** (7.x), **TJpg_Decoder** (Bodmer);
   - для сборки с Bluetooth ещё **NimBLE-Arduino 1.4.3**.
4. Инструменты:
   - Плата **ESP32C3 Dev Module** с разметкой **Partition Scheme: Minimal SPIFFS (1.9MB APP with OTA/190KB SPIFFS)**.

     Другой вариант: плата **Nologo ESP32C3 Super Mini** с разметкой **Huge APP**. Так прошивка выйдет на 16 КБ меньше, и именно так собирает GitHub. Настоящую разметку в обоих случаях задаёт файл `partitions.csv` в папке скетча.
   - **USB CDC On Boot: Enabled** — обязательно. Иначе вывод в монитор порта идёт через GPIO21 и сбрасывает экран.
   - **Erase All Flash Before Sketch Upload: Disabled** — иначе каждая прошивка стирает сеть, ключ и файлы.
5. Загрузить. Версия, собранная в Arduino IDE, показывается как «1». Номера сборок с GitHub больше, поэтому гаджет предложит обновиться.

Если плата не появляется в списке портов: зажмите кнопку **BOOT**, подключите USB и отпустите кнопку. Загрузите прошивку, затем нажмите **RST**.

## Первый запуск

Гаджет создаёт сеть Wi-Fi **DeepSeek-Setup**. Подключитесь к ней с телефона: откроется страница, где вводятся сеть Wi-Fi и ключ DeepSeek (получить его можно на platform.deepseek.com). Ключи и пароли хранятся только в памяти платы, в файлах прошивки их нет.

## Главный экран

После включения открывается главный экран, как у телефона:
- **Сверху** строка состояния: время, Wi-Fi, заряд, новые сообщения комнаты.
- **Ниже** иконки приложений 3×3 на нескольких страницах.

Ручкой выбирается иконка. Если упереться в край, открывается соседняя страница. Нажатие открывает приложение, удержание кнопки возвращает назад.

Приложения: DeepSeek, Комната, Игры, Калькулятор, Справочник, Конспекты, Сохранено, Википедия, Картинки, Галерея, Погода, Курсы, Часы, Таймер, Секундомер, Пульт (ИК), Bluetooth, Экран ПК, Телефон, Настройки, Админ.

**Если гаджет завис** — держите кнопку джойстика 6 секунд: он перезапустится и откроет главный экран. Это срабатывает, даже если программа намертво застряла (например, на SD-карте). Через 2 секунды экран гаснет, держите дальше.

Что настраивается:
- **Ось Y джойстика** — если вверх и вниз на ручке перепутаны.
- **Поворот экрана** — поворачивает картинку на 90° за нажатие, например чтобы держать гаджет боком. Ручка поворачивается вместе с картинкой.
- **Джойстик** — чувствительность: 1 — отклонять до упора, 5 — хватает лёгкого наклона.

## Возможности

- **Чат с DeepSeek.** Помнит переписку, ответ печатается по мере генерации. Есть «решить по шагам» и «объяснить проще». Удержание кнопки на клавиатуре чата открывает меню: новый чат, шаблоны вопросов, сохранённое.
- **Языки:** русский, английский, китайский. Экранная клавиатура с подсказками слов.
- **Тексты без интернета:** шаблоны вопросов, сохранённые ответы и конспекты.
- **Справочник:** формулы, константы, таблица Менделеева.
- **Калькулятор** с переменной x, графиками и уравнениями (см. ниже).
- **Интернет:** Википедия, картинки (Wikimedia Commons), погода, курсы ЦБ.
- **Время:** часы, таймер, секундомер.
- **Галерея:** картинки с телефона, с компьютера или из поиска. Без SD-карты хранится до 30 штук, с картой до 99.
- **Игры:**
  - шахматы против DeepSeek или самой платы;
  - «Подземелье 3D» — стрелялка от первого лица: ручка — идти и поворачивать, кнопка — выстрел;
  - «Песочница» — двумерный мир из блоков: копать, строить, мастерить кирки и мечи, ночью отбиваться от слизней; цель — золотая корона (см. ниже);
  - «Гонки», «Райдер», «Блоки», 2048, «Змейка», «Падающие блоки», «Лабиринт», «Память», «Пинг-понг», «Летящая птичка», «Арканоид», «Пришельцы», «Сапёр», «Повтори»;
  - «Куб-раннер» — уровень с финишем, шипами и платформами. Короткое нажатие кнопки или наклон джойстика вверх запускает забег, прыжок и повтор попытки. Удержание кнопки возвращает в меню. Прогресс и рекорд показываются в процентах.
  - игры с DeepSeek: «Викторина», «Приключение», «Угадай, кто я»;
  - общая таблица рекордов;
  - крестики-нолики через комнату и «Крестики рядом» по радио.
- **Пульт (ИК)** — пульты из базы Flipper-IRDB. Скачиваются с GitHub прямо с гаджета или загружаются файлом .ir с телефона. Только без SD-карты. Схема: GPIO8 → база NPN-транзистора (S9014), коллектор → 5V, эмиттер → «+» ИК-светодиода, «−» светодиода → резистор 33–68 Ом → GND.
- **Фонарик:** Настройки → Фонарик. Белый светодиод на GPIO2 через транзистор, схема в начале скетча рядом с `PIN_LED`. Только без SD-карты.
- **Пищалка** на GPIO20. Для активной пищалки в скетче поставьте `BUZZER_ACTIVE = true`. Звук настраивается: нет / сигналы / всё.
- **Wi-Fi и экран:** до 5 сетей Wi-Fi, автогашение экрана, заставка с часами.

## Телефон как пульт и клавиатура (Wi-Fi)

Приложение **«Телефон»** показывает адрес гаджета, например `http://192.168.1.35`. Подключите телефон к той же сети Wi-Fi и откройте этот адрес в любом браузере (Android или iPhone). Ничего устанавливать не нужно: гаджет сам отдаёт страницу.

На странице:
- **Стрелки.** Пока стрелку держат, это как наклон ручки.
- **OK.** Это как нажатие ручки. Если держать дольше полсекунды, получится долгое нажатие.
- **Поле для текста** с кнопками «Отправить» (вставить и нажать OK) и «Только вставить».

Пульт работает везде, где есть Wi-Fi: в играх, меню и при вводе текста. Из приложения «Телефон» можно выйти. Если связь пропала, нажатые кнопки отпускаются сами. Пульт есть только в полной сборке.

## Экран ПК (USB)

Приложение **«Экран ПК»** показывает на гаджете картинки и экран компьютера по USB-кабелю. На компьютере откройте в Chrome или Edge страницу [yacovgopnik.github.io/deepseek-pocket/pc.html](https://yacovgopnik.github.io/deepseek-pocket/pc.html), нажмите «Подключить» и выберите порт гаджета. Для передачи с ПК выберите «ПК → гаджет» в меню приложения. Монитор порта в Arduino IDE при этом должен быть закрыт.

- **Картинка.** Перетащите файл или вставьте через Ctrl+V, затем «Показать на гаджете» или «Сохранить в галерею».
- **Трансляция экрана.** Гаджет показывает выбранное окно, вкладку или весь экран, от 2 до 20 кадров в секунду.

- **Экран гаджета на ПК.** Выберите «Гаджет → ПК» на гаджете, вернитесь в меню и нажмите «Экран гаджета» на странице. Можно увеличивать изображение, открывать его на весь экран и сохранять PNG. На S3 изображение 240×240, на C3 — 120×120 для экономии памяти. Для остановки на гаджете снова откройте «Экран ПК» и выберите остановку трансляции. Доступно в полной сборке.

Как устроен обмен: страница сжимает кадр в JPEG 240×240 и передаёт его кусками по 2 КБ, гаджет подтверждает каждый кусок. Все подробности протокола — в начале раздела «ЭКРАН ПК» в скетче.

## Игры вдвоём рядом (без интернета)

**Игры → Крестики рядом** — два гаджета связываются напрямую по радио (ESP-NOW), без роутера и интернета, на расстоянии примерно до 100 м. На время игры Wi-Fi отключается от сети, а после игры подключается снова.

## SD-карта

| SD-модуль | ESP32-C3 |
|---|---|
| SCK | GPIO8 |
| MOSI | GPIO2 |
| MISO | GPIO20 |
| CS | GPIO9 |
| VCC | **5V** (у модуля свой стабилизатор 3,3 В; от 3V3 ему не хватает) |
| GND | GND, отдельным проводом к плате |

- **Конденсатор 100 мкФ** (можно вместе с керамическим 0,1 мкФ) ставится прямо на выводы VCC–GND модуля. Без него карта отвечает через раз: в момент обращения к ней проседает питание.
- **Два резистора по 10 кОм:** от GPIO2 к 3V3 и от GPIO9 к 3V3. При включении эти выводы должны быть в высоком уровне, иначе плата не загрузится.
- **Карта** до 32 ГБ, формат FAT32.

Включение: **Настройки → SD-карта**, гаджет перезапустится. Состояние видно там же: «работает», «не найдена» или «сбой N». После включения:
- галерея хранится на карте (папка `pics/`, до 99 картинок);
- в меню **Настройки → Обновление** появляется пункт **«Сборки на SD-карте»**: скачать обе сборки на карту (папка `fw/`) и переключаться между ними без интернета.

Заметки, сохранённые ответы и настройки остаются во внутренней памяти.

Если сразу после включения карта не отвечает, гаджет пробует снова каждые 15 секунд в течение 2 минут.

**Защита от зависания.** Если запуск с картой не дошёл до конца, на следующем запуске карта выключается сама, а на заставке видно, на каком шаге всё остановилось. Удержание кнопки при включении тоже выключает карту.

**Как устроено.** Шина SPI у платы одна, а у экрана нет вывода CS. Поэтому на время работы с картой выводы шины переключаются на неё, а потом обратно на экран. При переключении линия такта не дёргается: иначе экран без CS сбивается и перестаёт понимать команды.

**Проверка.** В папке [`tests`](tests) лежат отдельные скетчи:
- `sd_diag` проверяет карту медленно, быстро и вместе с экраном и пишет, в чём беда: питание и провода, длинные провода или прошивка;
- `sd_screen_test` по кругу переключается между картой и экраном.

## Песочница

**Игры → Песочница.** Мир 256×96 блоков создаётся заново для каждой новой игры: холмы, деревья, пещеры, уголь, железо, золото у самого дна. День длится 5 минут, ночь 3 минуты. Под землёй темно, и нужны факелы.

- **Управление.**
  - Ручка влево/вправо — идти, вверх — прыжок. Куда наклонена ручка, туда и цель (белая рамка).
  - Нажатие — ударить по блоку, поставить выбранный блок в пустое место или ударить слизня.
  - Удержание кнопки — меню: что ставить, мастерить, сохранить и выйти.
- **Инструменты** работают сами, пока лежат в рюкзаке: самая лучшая кирка копает, самый лучший меч бьёт. Без кирки копаются только земля, песок и дерево. Деревянная кирка берёт камень и уголь, каменная — железо, железная — золото.
- **Рецепты:**
  - доски — из брёвен;
  - верстак — из досок;
  - факелы — из угля или слизи с досками;
  - у верстака: кирки, мечи, кирпич и золотая корона.
- **Сохранение.** Мир весит около 25 КБ и хранится на SD-карте, а без неё — во внутренней памяти. Он сохраняется сам каждые 3 минуты, а также через меню «Сохранить и выйти».

## Три сборки: полная, с Bluetooth и игровая

Bluetooth весит около 250 КБ, и всё вместе в память на 4 МБ не помещается. Поэтому GitHub собирает три прошивки:

- **Полная сборка** (`firmware.bin`): всё, кроме Bluetooth.
- **Сборка с Bluetooth** (`firmware-ble.bin`): связь с телефоном по Bluetooth и пульт для музыки на телефоне. В ней **нет**:
  - картинок из интернета (галерея остаётся);
  - шахмат;
  - «Подземелья 3D» и «Гонок»;
  - «Райдера», «Викторины», «Приключения»;
  - ИК-пульта и фонарика;
  - пульта с телефона по Wi-Fi;
  - «Песочницы».
- **Игровая сборка** (`firmware-games.bin`): только игры (в том числе большие), «Комната», пульт с телефона и настройки. Здесь остаётся больше места под новые большие игры. Чата DeepSeek, справочника, калькулятора и остальных приложений в ней нет. Игры с DeepSeek работают, если задан ключ.

Переключение: **Настройки → Обновление → Сменить сборку** или **Сборки на SD-карте** (туда скачиваются все три). Настройки, сети и файлы сохраняются. Для сборки в Arduino IDE поставьте в начале скетча `#define ENABLE_BLE 1` (с Bluetooth) или `#define GAMES_EDITION 1` (игровая).

В сборке с Bluetooth включите **Настройки → Bluetooth**. Гаджет называется **DS-<метка>**.

- **Телефон как клавиатура и уведомления.**
  - Откройте в Chrome на Android страницу [yacovgopnik.github.io/deepseek-pocket/ble.html](https://yacovgopnik.github.io/deepseek-pocket/ble.html) и нажмите «Подключить». Подойдёт и приложение Serial Bluetooth Terminal в режиме Bluetooth LE.
  - Текст попадает в открытое поле ввода, например как вопрос DeepSeek. Если поле ввода не открыто, текст всплывает как уведомление.
  - Строка с `N:` в начале — всегда уведомление, с `T:` — только вставить.
- **Пульт для телефона.** На телефоне в настройках Bluetooth подключитесь к **DS-<метка>**. На гаджете откройте приложение Bluetooth → Пульт. Ручка влево и вправо переключает трек, вверх и вниз меняет громкость, нажатие ставит на паузу.

Wi-Fi и Bluetooth делят память. Если запросы в интернет начнут срываться, выключите Bluetooth.

## Страницы для телефона и компьютера

Страницы `ble.html` и `pc.html` лежат в корне репозитория. Их адреса `yacovgopnik.github.io/...` работают, когда в репозитории включён GitHub Pages: **Settings → Pages → Branch: main, папка / (root)**. Страница `room.html` открывает «Комнату» в браузере.

## Администратор

Один человек может быть администратором всех гаджетов с этой прошивкой. Команды подписываются ключом, который получается из логина и пароля админа (ECDSA P-256). В прошивке хранится только открытый ключ `ADMIN_PUBKEY`, по которому гаджеты проверяют подпись. Подделать команду без пароля нельзя, даже зная исходный код. Пароль нигде не записывается.

Как стать админом:

1. **Настройки → Администратор → Создать ключ**: ввести логин и пароль. Открытый ключ появится на экране и в мониторе порта (115200).
2. Вписать его в `ADMIN_PUBKEY` в начале скетча и выпустить новую версию.
3. **Настройки → Администратор → Войти** с теми же логином и паролем. Вход действует до перезапуска. На главном экране появляется приложение «Админ».

Что может админ:

- **Гаджеты на связи**: имя, комната, версия прошивки, заряд. Для каждого гаджета: обновить прошивку, перезапустить, выгнать из комнаты, заблокировать.
- **Объявление всем**: всплывает на экране всех гаджетов, в том числе тех, кто подключится позже.
- **Сообщения комнаты**: удалить сообщение у всех, заблокировать автора. Заблокированный не может писать, а его сообщения у других не показываются.
- **Закрепить в комнате**: строка сверху экрана комнаты.
- **Обновить все гаджеты / перезапустить все**.

Владелец гаджета видит каждое действие админа. Обновление и перезапуск начинаются через 10 секунд, и их можно отменить кнопкой.

Команды идут через тот же открытый сервер, что и «Комната». Поэтому их получают только гаджеты, у которых в комнате задано имя и включены «Сообщения в фоне». Старые и повторённые команды не принимаются: нужно точное время, гаджет берёт его из интернета.

## Калькулятор: функции, графики, уравнения

Клавиша **2nd** переключает на вторую страницу клавиш, **1st** возвращает обратно. Переменная **x** есть на обеих страницах.

- **Функции.** Вводите выражение с x: `2x²-3x+1`, `sin(x)/x`, `√x`, `3x^4`. Неявное умножение работает (`2x`, `3(x+1)`). Результата у такого выражения нет, калькулятор пишет «функция f(x)».
- **График y(x)** (2nd → `y(x)`):
  - вверх/вниз — масштаб, влево/вправо — сдвиг;
  - нажатие — курсор со значениями x и y, удержание — назад;
  - масштаб по y подбирается сам;
  - если выражение пустое, строится последняя функция;
  - для sin/cos/tan в градусах окно по умолчанию шире (720°).
- **Уравнения** (2nd → `x=?`). Знак равенства вводится клавишей `L=R`: `x²=x+2`, `3x^4=48`. Без знака равенства считается «выражение = 0».
  - Многочлены и одночлены до 8-й степени решаются точно: рациональные корни находятся целиком, показывается кратность корней, комплексные корни выводятся как `a ± bi`.
  - Остальные уравнения (`sin(x)=0,5`, `1/x=2`, `√x=2`) решаются приближённо: ищется смена знака на отрезке. Отрезок: [-100; 100], для тригонометрии в градусах [-720; 720], в радианах [-20; 20]. Корни, в которых график лишь касается оси, так не находятся.

## Комната

Гаджеты с этой прошивкой встречаются в общей комнате `lobby` на открытом MQTT-сервере `broker.emqx.io`.

- **Сообщения** идут в теме `dspocket/v1/<комната>` в виде `метка<TAB>имя<TAB>текст`.
- **Присутствие** («кто в комнате») — в теме `<комната>/p`.
- **Аватарки 24×24** — в теме `<комната>/a/<метка>`: 576 байт, сохраняемое сообщение.
- **Ответ DeepSeek:** сообщение, начатое с `@ai`, получает ответ, который видят все.

В комнату можно зайти и из браузера через страницу `room.html`.

Сообщения **не шифруются** и не хранятся: их видят все, кто сейчас в комнате. Не пишите туда пароли и личные данные. Сервер и комнату по умолчанию можно поменять в начале скетча (`MQTT_HOST`, `ROOM_DEFAULT`).

## Обновление по воздуху

На гаджете: **Настройки → Обновление**. Там есть «Проверить в интернете», «С телефона» (загрузить файл `.bin` через страницу гаджета) и «Сборки на SD-карте». Если обновление оборвалось, остаётся старая прошивка.

Новые версии собираются сами. При каждом изменении кода GitHub Actions собирает все три сборки и кладёт в папку `firmware/`:
- `firmware/firmware.bin` — полная сборка;
- `firmware/firmware-ble.bin` — сборка с Bluetooth;
- `firmware/firmware-games.bin` — игровая сборка;
- `firmware/version.txt` — номер версии.

Гаджет сравнивает этот номер со своим и предлагает обновиться. Репозиторий задаётся строкой `OTA_REPO` в начале скетча.

Китайский язык выключен (`ENABLE_CJK 0` в начале скетча), иначе прошивка не помещается в разметку с обновлением по воздуху.
